# gestion-pedagogica
# 📚 Sistema de Gestión Pedagógica

Sistema web para docentes de educación secundaria en México que permite gestionar grupos, alumnos y PDAs (Procesos de Desarrollo de Aprendizaje).

## ✨ Características

- 👥 Gestión completa de grupos y alumnos
- 📊 Seguimiento de canales de aprendizaje (Visual, Auditivo, Kinestésico)
- 📝 Sistema inteligente de PDAs basado en el Programa Sintético Fase 6
- 🎯 Registro de intereses y aspiraciones profesionales
- 📈 Estadísticas de grupo en tiempo real
- 🌓 Tema claro/oscuro
- 💾 Exportación/importación de datos

## 🚀 Cómo usar

1. Visita: [https://TU-USUARIO.github.io/gestion-pedagogica/](https://akali045.github.io/gestion-pedagogica/)
2. Establece una contraseña en tu primera visita
3. ¡Comienza a gestionar tus grupos!

## ⚠️ Importante

Esta aplicación guarda todos los datos localmente en tu navegador (localStorage). 

**Recomendación:** Exporta tus datos regularmente usando el botón "Exportar Datos" y guárdalos en un lugar seguro (Drive, Dropbox, USB).

## 🛠️ Tecnologías

- HTML5
- CSS3 (Custom Properties para temas)
- JavaScript Vanilla (sin frameworks)
- LocalStorage API
